# How to add new querys:

Add this json struct here and fill it out with data:
```json
  {
    "QueryName": "",
    "QueryVal": "",
    "QueryType": 1
  }
```

Possible query types:
- 0 -> Insert
- 1 -> Delete
- 2 -> Select
- 3 -> Update


---

# Why this design?

So you can easily edit querys and add more to it.
